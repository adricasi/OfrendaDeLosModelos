# Cultural review pack (NFR-010)

For: the cultural reviewer (a reader of Mexican background), via the founder.
**Deadline: send by Oct 31, 12:00 Spain time.** If there is no review by 17:00 the site is published
with the visible "Cultural review pending" note in the about panel (the flag
`culturalReviewPending` in `public/data/credits.json`; set it to `false` once reviewed).

What to check: that every ritual element and every Spanish text is accurate and respectful, that
nothing mocks the tradition or a model, that no Halloween or sugar-skull costume styling is implied,
and that the Spanish is written properly (accents, `¿ ?`, register). Please mark each row
OK / change to "…" / remove, and add notes at the end.

Sources the altar follows (also listed in the about panel, `public/data/credits.json`): UNESCO
(the tradition), Maxwell Museum "Making an Ofrenda" (the four elements: earth, wind, fire, water),
KUT (cempasúchil that lights the way), Detroit Institute of Arts (altar levels vary by region),
National Geographic (overview).
